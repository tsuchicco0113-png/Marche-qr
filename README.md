# Marché QR Maker

マルシェ・手づくり市の出店者向けの、オリジナルQRコード＆名刺メイカーです。
HTMLファイル1つで動き、サーバーもアカウント登録も要りません。

## できること

### 店頭モード（お客さま向け）
- **リンクまとめ名刺**：屋号・一言・リンク（最大5つ）を1枚のリンクページにまとめ、そのQRコードを作ります。lit.link などのページを持っていない人向けです。
- **URLをそのままQRに**：ショップなどへ直接飛ぶQRコードを作ります。
- リンクページの中身はURL自体に圧縮して入れるので、サーバーへの保存は不要です。
- **NFCタグ対応**：NTAG213 / 215 / 216 のどれに入るかを容量メーターで表示します。

### ビジネスモード（同業者・卸先向け）
- スキャンするとスマホの連絡先にそのまま登録される **vCard** 形式のQRコードを作ります。
- ロゴを連絡先のアイコンとして入れた **.vcf ファイル**の保存・共有もできます。

### デザイン・印刷
- ロゴ入りQRコード（誤り訂正Hで自動生成）
- 紙の色・質感（和紙・クラフト紙・画用紙・布目）、書体、インク色
- 名刺レイアウト4種（横・標準／縦型／写真メイン／写真背景）と写真の位置調整
- **A4 10面 名刺用紙**（91×55mm・2列×5段・フォーマット F10A4-1）への印刷と、0.1mm単位の位置微調整・位置確認シート
- QRコードの PNG / SVG 書き出し
- 設定内容の JSON 書き出し・読み込み

## 使い方

1. `index.html` をブラウザで開きます。
2. 左の入力欄に屋号やリンクを入れると、右に名刺・QRコード・リンクページのプレビューが出ます。
3. 名刺を印刷するか、QRコードを画像で書き出して使います。

### リンクまとめ名刺を使う場合
リンクまとめ名刺のQRコードは「このHTMLを公開した場所」を開くURLになります。
このリポジトリを GitHub Pages で公開すれば、そのURLがそのまま全員共通の表示ページになります。

1. リポジトリの **Settings → Pages** で、Branch を `main`（`/ (root)`）にして保存します。
2. 公開されたURL（例：`https://<ユーザー名>.github.io/marche-qr/`）を開いて使います。公開場所の欄は自動で入ります。

自分のサイトや Netlify などに `index.html` を置いて使うこともできます。

### NFCタグへの書き込み
「URLコピー」でコピーした内容を、アプリ「NFC Tools」の **URL** レコードとして書き込みます。読み取る側はアプリ不要です。

## 印刷のコツ
- 印刷画面では「用紙サイズ：A4」「倍率：100%（実際のサイズ）」「余白：なし」を選んでください。
- 本番前に普通紙で「位置確認シート」を刷り、本番用紙に重ねて光に透かしてずれを確認すると安心です。

## 動作環境
最新の Chrome / Edge / Safari / Firefox。スマートフォンでも使えます。
入力内容はお使いのブラウザ内（localStorage）にだけ保存され、外部には送信されません。
